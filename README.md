# 裂教与正统 · 基督教思想分裂通史

一部面向**零基础读者**、但力求专业深度的基督教思想史导览：从公元 1 世纪直到今天，把两千年来每一次教义分裂的来龙去脉、每个派别的主张、敌人与所受的反驳讲清楚。

**在线阅读**：https://lunwhale.github.io/schism-and-orthodoxy/

## 这本书是什么

- **6 部 23 章 + 2 个附录**，渲染后正文约 21.8 万字
- **153 条术语库**：正文中带虚线的词都可点击，含希腊文/拉丁文原文、词源、误译分析与相关词条
- **154 条大事年表**
- **49 张派别卡片**：主张／来历／要解决的问题／论敌／所受反驳／结局现状，六字段统一格式
- **80 张专题表格**、**85 个「为什么会有争议」方框**、**48 个「常见误解」方框**
- **六张「争论的温度计」**：每一部末尾把该时期的争论压成「核心争议词 / 历史触发器 / 各方立场 / 今天的影响」

## 技术说明

- **单文件、离线可用**：`index.html` 内嵌全部 CSS / JS / 正文 / 术语库 / 年表，无任何外部依赖，可直接双击打开。
- **阅读层级**：总览（隐藏史料与注框）／标准（显示注框）／深潜（全部展开）。
- **检索**：`/` 或 `⌘K` 全文搜索。
- **构建链**：正文用 Markdown 写在 `source/data/*.md`，由 `source/build/build.js` 编译成单文件 HTML。

```bash
cd source && node build/build.js   # 重新生成
node build/check.js                 # 结构校验（块配平 / 表格列数 / 术语完整性）
```

## 立场说明

本书**不是护教书，也不是反教书**。对每个派别，先按它自己的理解讲清楚，再讲别人怎么反驳它；区分「史实」「史料争议」「神学判断」三层；外部批判（犹太教、伊斯兰教、其他宗教、无神论、世俗主义）与内部论战同等分量。
