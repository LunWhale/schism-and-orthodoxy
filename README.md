## 写作立场

这本书**不是护教书，也不是反教书**：

1. **对每个派别，先按它自己的理解把它讲清楚**，再讲别人怎么反驳它。
2. **区分「史实」「史料争议」「神学判断」三层**。
3. **外部批判与内部论战同等分量**——犹太教、伊斯兰教、印度教/佛教/中国宗教、无神论、世俗主义，都单独成章。

凡本书自己也无法裁决的地方，就直说无法裁决（恶的问题、神的隐晦、圣经的道德难题、教宗首席权都属此类）。

## 已知局限

- **AI 的训练数据本身带有偏向**：英语学界比重偏高、近现代研究比重偏高。某个传统若被讲得太薄，很可能就是这种偏向的表现。
- **人工审查不等于同行评审**：能发现明显错误，无法替代专业学者的逐条核校。
- **「尽可能列举所有派别」在原理上不可能完成**：全球有数万个基督教宗派，本书只能选「有代表性的」与「影响大的」，并在附录补遗。
